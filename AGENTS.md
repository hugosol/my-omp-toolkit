## Agent skills

### Issue tracker

Issues and specs live as markdown files under `.scratch/` in this repo; decision tickets use the `open`/`claimed`/`resolved` lifecycle. See `docs/agents/issue-tracker.md`.

### Triage labels

Implementation tickets use `needs-triage`/`needs-info`/`ready-for-agent`/`ready-for-human`/`wontfix`, with `in-progress`/`closed` tracking execution. See `docs/agents/triage-labels.md`.

### Domain docs

Multi-context: `GLOSSARY-MAP.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
