## Agent skills

### Issue tracker

Issues and specs live as markdown files under `.scratch/` in this repo. See `docs/agents/issue-tracker.md`.

### Triage labels

Decision tickets: `open` / `claimed` / `resolved`; implementation tickets: `ready-for-agent` / `ready-for-human` / `in-progress` / `closed`; shared: `needs-triage` / `needs-info` / `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
